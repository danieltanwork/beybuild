# BeyBuild project memory

Before making non-trivial changes, read:
- `memory.md` — durable architecture decisions and lessons (why things are
  built the way they are, what's already been tried and abandoned).
- `progress.md` — current status, changelog, and what's in progress next.

Keep both up to date as you work: append lessons/decisions to `memory.md`
when something durable is learned (not routine bug fixes), and update
`progress.md`'s "current state" and changelog when a feature lands or a
task's status changes.
